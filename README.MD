# Assignment 2 - Advanced CSS

This project was created for Assignment 2 - Advanced CSS.

The main goal of this assignment is to practice using **Flexbox** and **CSS Grid** to create different web page layouts.

## Tasks

### Task 0 - Navigation Bar

Created a navigation bar with:

* Logo
* Navigation links
* Flexbox layout
* Hover effect for links

### Task 1 - Card Row

Created a row of three cards using Flexbox.

Each card contains:

* Image
* Title
* Description
* Button

A hover effect was also added to the cards.

### Task 2 - Page Layout

Created a page layout using CSS Grid.

The layout contains:

* Header
* Sidebar
* Main content
* Footer

The layout uses `grid-template-areas`.

### Task 3 - Image Gallery

Created an image gallery using CSS Grid.

The gallery contains 9 images arranged in rows and columns.

A hover effect with image captions was added.

### Task 4 - Portfolio Page

Created a simple portfolio page using both Flexbox and CSS Grid.

The page contains:

* Header
* Projects section
* Sidebar
* Footer

Flexbox is used for the header and project cards, while CSS Grid is used for the main page layout.

## Technologies

* HTML5
* CSS3
* Flexbox
* CSS Grid
